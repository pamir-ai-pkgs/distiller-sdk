# AI Modules (Removed)

> **Removed in SDK v4.0.0**: Speech processing modules (Parakeet ASR, Piper TTS, Whisper ASR) have been removed from the Distiller SDK.
>
> These capabilities are now available as speech skills in **distiller-cc >= 6.0.0**.

## Migration

If you were using `distiller_sdk.parakeet`, `distiller_sdk.piper`, or `distiller_sdk.whisper`, install `distiller-cc >= 6.0.0` which provides equivalent functionality as runtime skills with automatic model downloading.
